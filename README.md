# FreewarChestPuzzle

Greasemonkey script which adds a visualization of the chest puzzles in the
MMORPG [Freewar.de](https://www.freewar.de/).

Import `FreewarChestPuzzle.user.js` as User-Script in Greasemonkey/Tampermonkey
and start Freewar.
